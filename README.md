# Merge & Munch — iOS

Native SwiftUI source for current iOS releases. Create an iOS App target named `MergeAndMunch` in Xcode with the current iOS deployment target, then add `Sources/MergeAndMunch` to that target.

The client includes the original end-to-end loop: harvest farm plots, merge ingredients on the market board, serve customer orders for coins and stars, buy farm decorations, and persist the game state with `UserDefaults`. Test on an iOS 16+ simulator or device using the latest installed Xcode SDK.
